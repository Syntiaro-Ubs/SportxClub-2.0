Technical Architecture
Internal Payment Engine — Node.js

1. Frontend → Create Order API

React app calls /api/payment/create-order with booking details

2. Node.js → Razorpay Order + Route

Server creates Razorpay Order with transfers[] array specifying owner's linked account & split amount

3. Frontend → Razorpay Checkout Popup

Razorpay Checkout.js opens — player pays via UPI/Card

4. Frontend → Verify Signature

Server verifies HMAC-SHA256 signature to confirm payment is genuine

5. Razorpay → Webhook Notification

Backup confirmation via payment.captured webhook event

6. Cron Job → Release Hold & Settle

Nightly batch releases held funds to owner's bank (T+2)
